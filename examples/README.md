# Examples

This directory contains representative generated artefacts from the thesis workflow.

The examples are provided to illustrate the output formats and are not the complete experimental output corpus.

## Baseline Example

The baseline example contains:

- `risk-register-baseline.html` – human-readable HTML risk register generated by the workflow.
- `sensitivity-baseline.json` – per-element JSON dataset exported for offline analysis and verification.

These files are derived artefacts and can be regenerated from the versioned workflow, scripts, and IFC inputs in the repository.
