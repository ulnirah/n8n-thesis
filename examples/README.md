# Examples

This directory contains the baseline outputs generated for the eight IFC models in the thesis corpus.

The complete fault-injection experiment produces a substantially larger set of outputs and is not committed wholesale to the repository. The baseline outputs are retained here to provide concrete examples of the workflow's generated artefacts for every corpus model.

## Relationship to the Full Experiment

These files represent the unmodified baseline corpus only.

The fault-injection experiments additionally generate outputs for:

- F1: Mandatory property deletion
- F2: Value emptying
- F3: Quantity-field deletion
- F4: Quantity-magnitude perturbation
- F5: Property-set deletion
- F6: Element deletion

at the three severity levels defined in the thesis, with additional dual-file runs for F4 and F6.

Those generated outputs are not stored in this directory as a complete experimental archive. The workflow, fault-injection script, corpus, and experimental design are provided so that the full set can be regenerated.

## Naming Convention

Risk-register files use the general pattern:

```text
risk-register-<model>-<timestamp>.html
```

Sensitivity datasets use:

```text
sensitivity-<model>.json
```

The timestamp in the risk-register filename identifies the workflow execution that produced the report. The corresponding sensitivity dataset is identified by model rather than execution timestamp.
